# Prácticas de Python — archivo histórico de Drive (2020)

Estas 15 prácticas provienen de una carpeta histórica de Drive. Se mantienen separadas de la cursada UBA del segundo cuatrimestre de 2025 porque su institución, fecha y contexto no están confirmados como idénticos.

La organización temática sólo facilita la lectura y no implica que los archivos formen una aplicación única:

- `condicionales/`
- `bucles-y-generadores/`
- `funciones/`
- `colecciones/`
- `excepciones/`

Los nombres fueron normalizados para el repositorio; el contenido de los scripts se conserva como registro histórico. El análisis técnico está en [`../docs/archivo-historico-drive.md`](../docs/archivo-historico-drive.md).
