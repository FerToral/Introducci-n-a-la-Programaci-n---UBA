# Guía 6 — Funciones y estructuras de control

Introducción a Python: definición de funciones, operaciones aritméticas, condicionales, ciclos y alcance de las variables.

## Contenido

- [`src/guia6.py`](src/guia6.py): suma, terna pitagórica, múltiplos, conversión de temperaturas, números primos y ejemplos de iteración.
- [`src/alcance_variables.py`](src/alcance_variables.py): ejemplos de paso de argumentos, retorno y modificación de una variable global. Se ejecuta directamente para observar la salida de los ejemplos.
- [`tests/test_guia6.py`](tests/test_guia6.py): pruebas de funciones y casos límite.

Es una selección de ejercicios de clase; la guía completa incluye otras consignas.
