# Guía 7 — Listas, cadenas y matrices

Recorridos de secuencias, pertenencia, acumulación, extremos, orden estricto, palíndromos y análisis de filas y columnas de una matriz.

## Contenido

- [`src/guia7.py`](src/guia7.py): implementaciones de los ejercicios incluidos.
- [`tests`](tests): 45 pruebas sobre los ejemplos, casos límite y propiedades de las funciones.

Las funciones de consulta conservan sus entradas. Las comprobaciones de orden son estrictas: dos elementos consecutivos iguales hacen que la secuencia no esté ordenada. Para las operaciones de máximo y mínimo se requiere una lista no vacía; para columnas se requiere una matriz rectangular no vacía.

La selección no cubre todas las consignas de la guía.
